# 将棋走（しょうぎそう）

チャリ走風の横スクロールゲーム。将棋の駒を選んで、右から流れてくる道の穴をジャンプで避けながら走り抜けます。落ちたら負け。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

1. 8種類の駒から1つを選ぶとゲームスタート（キーボードの `1`〜`8` でも選択可）
2. 穴や段差の手前でジャンプ。長押しで高く、短く押すと低く跳びます
3. 穴に落ちる、段差・壁・穴の向こう岸にぶつかる、画面の左からはみ出すとアウト
4. 進むほどスピードが上がり、穴が増えて広くなり、坂や段差の高低差と壁の高さも大きくなります

駒は地上を走っている間、少しずつ基本の位置へ戻ります。

### 飛んでくる相手の駒

右から相手の駒（逆さ向き）が飛んできます。当たると

- 自分と同じ駒 → +500点
- 苦手な駒 → アウト（「取られた…」）
- その他の駒 → +100点

得点は「走った距離(m) + 取った駒の得点」です。

### 操作

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| ジャンプ | Space / ↑ / Z | A |
| スキル | X | B |
| 駒を選び直す（ゲームオーバー時） | Esc | 駒を選び直す |

スマホを横向きにすると、A・B ボタンがゲーム画面の左右下に重なって表示されます。

## 駒の性能

| 駒 | ジャンプ（A） | スキル（B） | 苦手 |
| --- | --- | --- | --- |
| 歩兵 | 小さなジャンプ | なし | なし |
| 香車 | 画面の上まで一気に跳ぶ（押す長さで変わらない） | なし | 歩兵 |
| 桂馬 | 右斜め前（75°）に跳ぶ | 左斜め後ろ（115°）に跳ぶ | 銀将 |
| 銀将 | 標準のジャンプ | 押している間、滑空（1回の滞空で約1.5秒まで） | 金将 |
| 金将 | 二段ジャンプ | なし | 桂馬 |
| 角行 | 斜め前（45°）へ画面の上まで一直線に跳ぶ | 斜め後ろ（135°）へ画面の上まで一直線に跳ぶ | 香車 |
| 飛車 | 空中でもう一度押すと、その高さのまま前へまっすぐ移動 | 空中で押すと、その高さのまま後ろへまっすぐ移動 | 歩兵 |
| 王将 | 三段ジャンプ | なし | なし |

飛車の前後移動は、1回の滞空でどちらか1回だけ使えます。
角行は前後に大きく動くので、基本の位置が他の駒より右寄りです。
性能は `src/pieces.js` の数値で調整できます（各項目の意味はファイル先頭のコメント参照）。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — 見た目
- `src/pieces.js` — 駒の定義（ジャンプ性能・スキル）
- `src/game.js` — ゲーム本体（コース生成・物理・描画・入力）
