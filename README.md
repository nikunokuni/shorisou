# 将棋走（しょうぎそう）

チャリ走風の横スクロールゲーム。将棋の駒を選んで、右から流れてくる道の穴をジャンプで避けながら走り抜けます。落ちたら負け。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

1. 8種類の駒から1つを選ぶとゲームスタート（キーボードの `1`〜`8` でも選択可）
2. 穴や段差の手前でジャンプ。長押しで高く、短く押すと低く跳びます
3. 穴に落ちる、段差や穴の向こう岸の壁にぶつかる、画面の左からはみ出すとアウト
4. 進むほどスピードが上がり、穴が増えて広くなり、坂や段差の高低差も大きくなります

駒は地上を走っている間、少しずつ基本の位置（画面の左寄り）へ戻ります。

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| ジャンプ | Space / ↑ / Z | ジャンプ |
| スキル | X | スキル |
| 駒を選び直す（ゲームオーバー時） | Esc | 駒を選び直す |

## 駒の性能

| 駒 | ジャンプ | スキル |
| --- | --- | --- |
| 歩兵 | 小さなジャンプ | なし |
| 香車 | 画面の上まで一気に跳ぶ（押す長さで変わらない） | なし |
| 桂馬 | 右斜め前（75°）に跳ぶ | 左斜め後ろ（115°）に跳ぶ |
| 銀将 | 標準のジャンプ | 押している間、滑空（1回の滞空で約1.5秒まで） |
| 金将 | 二段ジャンプ | なし |
| 角行 | 大きく滑空する（少し浮遊あり） | なし |
| 飛車 | 空中でもう一度押すと、その高さのまま前へまっすぐ移動 | 空中で押すと、その高さのまま後ろへまっすぐ移動 |
| 王将 | 三段ジャンプ | なし |

飛車の前後移動は、1回の滞空でどちらか1回だけ使えます。
性能は `src/pieces.js` の数値で調整できます（各項目の意味はファイル先頭のコメント参照）。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — 見た目
- `src/pieces.js` — 駒の定義（ジャンプ性能・スキル）
- `src/game.js` — ゲーム本体（コース生成・物理・描画・入力）
