# 将棋走（しょうぎそう）

チャリ走風の横スクロールゲーム。将棋の駒を選んで、右から流れてくる道の穴をジャンプで避けながら走り抜けます。落ちたら負け。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

1. 8種類の駒から1つを選ぶとゲームスタート（キーボードの `1`〜`8` でも選択可）
2. 穴や段差の手前でジャンプ。長押しで高く、短く押すと低く跳びます
3. 穴に落ちる、または段差や穴の向こう岸の壁にぶつかるとアウト
4. 進むほどスピードが上がり、穴が増えて広くなり、坂や段差の高低差も大きくなります

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| ジャンプ | Space / ↑ / Z | ジャンプ |
| スキル（未実装） | X | スキル |
| 駒を選び直す（ゲームオーバー時） | Esc | 駒を選び直す |

## 駒ごとのジャンプ

| 駒 | 特徴 |
| --- | --- |
| 歩兵 | 小さなジャンプ |
| 香車 | 低く長く跳ぶ |
| 桂馬 | 高く鋭い大跳躍 |
| 銀将 | 下降中に押し続けるとふわっと浮く |
| 金将 | 二段ジャンプ |
| 角行 | 大きく滑空する（少し浮遊あり） |
| 飛車 | 力強い二段ジャンプ |
| 王将 | 三段ジャンプ |

性能は `src/pieces.js` の数値で調整できます。

## 2つ目のボタン（スキル）

各駒の `skill` に関数を設定すると、スキルボタン / X キーで呼び出されます（現在はすべて `null` で「準備中」表示）。

```js
skill: (player) => { player.vy = -10; },
```

## ファイル構成

- `index.html` — 画面構成
- `style.css` — 見た目
- `src/pieces.js` — 駒の定義（ジャンプ性能・スキル）
- `src/game.js` — ゲーム本体（コース生成・物理・描画・入力）
